# Journal de Bord - Guitar Hunter AI

Le journal est découpé **par semaine ISO** (lundi → dimanche) : un fichier `journal/AAAA-Wss.md` par semaine, entrées les plus récentes en haut. Ce fichier est l'**index** ; il ne contient plus d'entrées.

## Convention

- **Où écrire** : dans le fichier de la semaine **de la date de l'entrée** (créer `journal/AAAA-Wss.md` avec l'en-tête `# Journal — semaine AAAA-Wss (du … au …)` si la semaine n'existe pas encore), **en tête du fichier**.
- **Format d'une entrée** : `[AAAA-MM-JJ] [MODÈLE] Action effectuée → Résultat.` puis des puces si besoin. Dates absolues uniquement.
- **Mettre à jour la table ci-dessous** (nombre d'entrées) quand on ajoute une entrée ou une semaine.
- Les renvois du type « voir `JOURNAL.md`, 2026-09-21 » restent valables : chercher la date dans la table pour trouver la semaine.

## Notes sur l'historique

- Découpage fait le 2026-10-03 à partir du fichier unique (800 Ko, 383 entrées) ; **le texte des entrées n'a pas été modifié** (déplacement vérifié à l'octet près). L'ancien fichier unique reste dans l'historique git.
- 23 anciennes entrées au format `### **Date: JJ/MM/AAAA** (Session N)` (février 2026) sont rangées dans la semaine de leur date, sans changement de format.
- Deux entrées portaient la date `2024-07-30`, manifestement une faute de frappe (placées entre des entrées du 27 et du 28 février 2026) : rangées dans la semaine 2026-W09 ; leur date écrite n'a pas été corrigée.
- Le journal n'était pas strictement chronologique (entrées insérées après coup) : chaque entrée est rangée selon **sa propre date**, l'ordre relatif d'origine étant conservé à l'intérieur d'une semaine.
